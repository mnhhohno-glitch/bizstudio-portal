# 初回面談 台本（確定版）

- 〔 〕は、求職者ごと・答えごとに自動で差し込む部分。
- ［ ］は、CAが相手の答えを聞いて押すボタン。押した内容で、次のセリフと拾う一言が切り替わる。
- 「拾う一言」は、答えを受け止めて次へつなぐための一言。新人が迷わないための見本。

## 新人向けの注意（台本の冒頭に表示）

- ほめるときは、相手が言った言葉を1つそのまま入れる（例：「〇〇まで任されていたんですね」）。
- 「同じ方はたくさんいらっしゃいます」は、何度も言うとくどくなる。1回の面談で1〜2回まで。
- 退職理由は否定しない。前の会社を一緒に悪く言わない。受け止めて、次の探し方につなげる。
- 答えに自信がない質問は、その場で答えなくてよい。「確認して、改めてご連絡いたしますね」と持ち帰る。
- 事務希望の人は、選考でExcelをよく見られる。関数まで使えるかは必ず具体的に聞く。

## 差し込みの一覧

| 差し込み | 出どころ |
|--|--|
| 〔氏名〕 | 求職者の氏名 |
| 〔CA名〕〔CA姓〕 | ログイン中のアカウントの社員名の名字（空白で分けた先頭。空白が無ければ社員名全体。T-207 の案内メールの〔CA姓〕と同じ取り方） |
| 〔時刻〕 | 面談記録の「時刻」欄。空なら「本日〇時から」の部分を省く |
| 電話／オンライン | 面談記録の「時間/手法」欄。空なら電話の版 |
| 〔直近の会社〕 | 登録情報の職歴で一番新しい会社名 |
| 〔学校名〕〔学部学科〕〔卒業年〕 | 登録情報の学歴 |
| 〔会社名〕〔入社年月〕〔仕事内容〕 | 登録情報の職歴 |
| 面談準備の質問 | 面談準備の「面談で聞くこと」（その会社に関わるものを経歴確認に差し込む。食い違いを先に） |
| 〔頭の文字〕 | 登録メールアドレスの先頭の文字 |

（会社名が読み取れないときは「現在は、お仕事をされていますか？」）

［在職中］［辞めている］

### 退職の予定
**［在職中］**
> ありがとうございます。退職の時期は、もう決まっていらっしゃいますか？

［決まっている］［決まっていない］
- ［決まっている］
  > いつ頃のご予定でしょうか？
- ［決まっていない］
  > 承知しました。では、もし内定が出て、今の会社に退職をお伝えした場合、そこから何ヶ月くらいで退職できそうでしょうか？ 引き継ぎなども含めて、目安で大丈夫です。

**［辞めている］**
> ありがとうございます。ご退職されたのは、いつ頃でしょうか？

拾う一言：
- 決まっている → 「承知しました。では〇月以降の入社を目標に、逆算して進めていきましょう。」
- 決まっていない・1〜2ヶ月で辞められる → 「ありがとうございます。一般的にも1〜2ヶ月前にお伝えする方が多いので、それを前提に考えていきますね。」
- 3ヶ月以上かかりそう → 「承知しました。応募先によっては入社日の相談が必要になるので、その点も踏まえて進めていきますね。」
- 辞めている → 「ありがとうございます。では、入社の時期は合わせやすい状況ですね。」

入力先：転職時期の横のメモ欄

> これまでに、何社くらい応募されましたか？ ざっくりで大丈夫です。

- 1社以上のとき

  - 続いている会社があるとき
    > 差し支えなければ、どんな業界やお仕事の会社か教えていただけますか？

拾う一言：
- 0社 → 「承知しました。では、応募先選びからしっかり一緒に考えていきましょう。」

### 相談の背景
> 今回、エージェントに相談してみようと思われたのは、どんなことにお困りだったからでしょうか？

拾う一言：
- 合う求人が見つからない・条件が多い → 「ありがとうございます。条件が多いときこそ、優先順位を一緒に整理すると探しやすくなりますので、このあと細かくお伺いしますね。」
- 求人が多すぎて違いが分からない → 「たしかに、似た求人が多くて見分けにくいですよね。求人ごとの違いや、見るべきポイントもしっかりお伝えしていきます。」
- 初めてで、何から始めればいいか分からない → 「初めてだと、分からないことばかりですよね。進め方から一つずつご案内しますので、ご安心ください。」
- 書類や面接が不安 → 「ありがとうございます。書類と面接の対策は、先ほどご説明したとおり、しっかりお手伝いします。」
- 特にない・なんとなく → 「承知しました。では、今日のお話の中で気になることが出てきたら、いつでもおっしゃってください。」

     > 差し支えない範囲で構わないのですが、〔会社名〕様を退職されたのは、どんな理由からでしたか？
   - 今の会社のとき
     > 差し支えない範囲で構わないのですが、今回、転職を考え始めたきっかけは何だったのでしょうか？ いつ頃から考え始められましたか？
   - 理由がいくつか出たとき
     > ありがとうございます。その中で、一番大きかった理由はどれでしょうか？

拾う一言（仕事の中身・立場）：
- 長く勤めている → 「〇年も続けてこられたのは、それだけで大きな強みです。一つの会社で信頼を積み上げてこられたことは、企業側もしっかり見てくれるポイントですよ。」
- 仕事を具体的に話してくれた → 「ありがとうございます、とても分かりやすいです。〇〇（相手の言葉）まで任されていたんですね。」
- 数字の実績がある → 「〇〇（数字）はすごいですね。数字で成果を示せるのは大きな強みなので、書類や面接でもしっかり打ち出していきましょう。」
- 数字が無い・分からない → 「大丈夫です。数字が無くても、任されていたことや工夫されたことは十分に強みになりますので、一緒に言葉にしていきましょう。」
- リーダー・教育係の立場 → 「〇人のチームをまとめて、後輩の育成まで任されていたんですね。人をまとめた経験は、どの業界でも評価されやすいですよ。」
- 自分から工夫・改善した → 「ご自身で考えて、やり方を変えていかれたんですね。言われたことだけでなく自分から動けるのは、立派な強みです。」
- 選んだ理由がはっきりしている → 「ご自身の軸を持って選ばれていたんですね。その軸は、今回の転職でも大事にしていきましょう。」
- 大変な環境だった → 「その環境で〇年頑張ってこられたのは、本当に大変だったと思います。」

拾う一言（退職理由）：
- 人間関係 → 「それは毎日のことですし、本当にお辛かったですよね。実は、人間関係をきっかけに転職される方はとても多くて、環境を変えたことでのびのび働けるようになった方もたくさんいらっしゃいます。ご安心ください。次は、職場の雰囲気もしっかり見ながら一緒に探していきましょう。」
- 残業・仕事量が多い → 「その量を毎日こなしてこられたのは、本当に大変だったと思います。働き方を見直したいという理由で転職される方は多く、無理のない環境に移って活躍されている方もたくさんいらっしゃいます。働き方もしっかり条件に入れて探していきましょう。」
- 給与・評価 → 「頑張っているのに、それがきちんと評価されないのは本当にもどかしいですよね。同じ理由で転職を考える方はとても多く、評価の仕組みが整った会社に移って、納得して働けるようになった方もたくさんいらっしゃいます。評価のされ方も一緒に見ながら、求人を選んでいきましょう。」
- 通勤・家庭の事情 → 「ご家庭のことを考えると、本当に大事なポイントですよね。生活の変化をきっかけに転職される方は多く、家庭と両立しながら働ける職場に移られた方もたくさんいらっしゃいます。ご安心ください。無理なく続けられる環境を一緒に探しましょう。」
- 将来が見えない・成長できない → 「今のうちから先のことまでしっかり考えていらっしゃるのは、素晴らしいと思います。同じように将来を考えて一歩踏み出される方は多く、新しい環境でキャリアを広げている方もたくさんいらっしゃいます。その先まで見据えて、一緒に選んでいきましょう。」
- 仕事内容が合わない → 「実際にやってみたからこそ分かったことですよね。合わないと感じて仕事を変える方は多いですし、その経験を生かして次の仕事で活躍されている方もたくさんいらっしゃいます。今回の経験は、次の仕事選びの大事なヒントになりますよ。」
- 言いにくそう → 「もちろん、話せる範囲で大丈夫ですよ。どんな理由であっても、同じような思いで転職される方はたくさんいらっしゃいますので、ご安心ください。面接で聞かれたときの伝え方は、また一緒に考えましょう。」

入力先：職務経歴（会社名・期間・雇用形態・職種・仕事内容）、各社の退職理由

## B. そのまま（画面の選択肢に合わせない）もの
- **Word・PowerPoint**：まとめて1つ聞く形のまま。［どちらも問題ない］→ Word 中級・PPT 中級／［Wordだけ］→ Word 中級・PPT 不可／［PowerPointだけ］→ Word 不可・PPT 中級／［どちらも苦手］→ Word 初級・PPT 初級。
- **転勤**（`d.desiredTransfer`）：台本の4つのボタンのまま。［全国OK］→ 可／［エリア限定ならOK］→ 要相談（エリアは `d.desiredTransferMemo`）／［通える範囲ならOK］→ なし（`d.desiredTransferMemo` に「通える範囲の異動なら可」）／［難しい］→ なし。事務：［大丈夫］→ 可／［難しい］→ なし。［将来ならOK］［将来も難しい］は `d.desiredTransferMemo`。

## C. 画面に出す欄・足す選択肢
- 画面に出す（DB列はすでにある）：在職状況 `d.employmentStatus`（転職活動状況）、退職日 `d.resignationDate`（転職活動状況）、年間休日 `d.desiredHolidayCount`（希望休日の隣）、大事にしたい条件 `d.priorityCondition1〜3`（希望条件タブの最後）。
- 選択肢を足す：自動車免許「取得(AT限定)」、希望残業「45時間超も可」。

## D. 入れ先の決まり（対応表の「欄が無い」もの）
- 年収の内訳（賞与・月給・手取り・残業代込みか・交通費）→ `d.currentSalaryMemo`。希望の月手取り → `d.desiredSalaryMinMemo`。理想の月給 → `d.desiredSalaryMaxMemo`。
- 勤務地の最寄り駅・通勤手段・通勤時間・引っ越し → `d.desiredAreaMemo`。
- 職歴の選んだ理由・仕事の中身・立場・人数・数字 → `wh.jobTypeMemo`（見出し「【選んだ理由】」などを付ける）。
- 退職の予定・退職できるまでの月数 → `d.jobChangeTimelineMemo`。退職した時期 → `d.resignationDate`。
- 希望職種・業種・エリアは、聞いた言葉を各メモ欄（`d.desiredJobType1Memo`・`d.desiredIndustry1Memo`・`d.desiredAreaMemo`）に入れるだけ。一覧（マスタ）からの選択は、面談後にCAが入力画面で行う。避けたい職種・業種もメモ欄。
- 次回面談の電話／オンライン → `d.nextInterviewMemo`。日時を入れたら `d.nextInterviewFlag` を「設定済」。

## E. 退職理由
- ボタンから「大・中」を自動で入れる（`wh.resignReasonLarge / Medium`）。小分類は、下の候補だけを出してCAが1つ選ぶ。
  - 人間関係：過去型／個人都合／「上司・同僚との人間関係」「ハラスメント（パワハラ・セクハラ等）」
  - 残業・仕事量：過去型／個人都合／「長時間労働・過重労働」「残業や休日出勤が多い」
  - 給与・評価：過去型／個人都合／「給与・待遇が見合わない」「評価制度への不満」「昇給・昇進がない」
  - 通勤・家庭の事情：過去型／環境要因／「通勤時間が長い・転居により通勤困難」「家庭の事情（育児・介護）」
  - 将来・成長：未来型／キャリア志向／「より成長できる環境を求めて」
  - 仕事内容が合わない：過去型／個人都合／「仕事内容が合わない・ギャップがある」
  - 言いにくい：選択は空のまま、`wh.jobChangeReasonMemo` に「言いにくい」
- 文字の値は `src/constants/resign-reason-hierarchy.ts` の実際の文字列に合わせる。

## F. 保存と入力画面への入れ方
- 押したボタンの言葉は、新しい表（面談1件に1行、答えは JSON、台本の版番号つき）に保存する。
- 欄が空のときだけ自動で入れる。すでに値があれば勝手に変えず、欄の横に「台本の答え（〇〇）に替えますか？」を出し、CAが押したときだけ替える。
- メモ欄は、空なら入れ、入っていれば末尾に「【台本】」を付けて書き足す（同じ文がすでにあれば足さない）。
- ボタンを押し直したとき、欄が前に台本が入れた値のままなら差し替え、CAが手で直していたら触らない。
- 入れるのは画面の状態に対して行い、既存の自動保存で保存する（サーバーで直接書かない）。
- 2回目の面談に、前回の台本の答えは持ち越さない。

## G. チャットの「よく使う質問」のボタン（面談準備チャットの入力欄の上）
| ボタン | 動き |
|--|--|
| ［職種を説明］ | 入力欄に「〔　〕という職種を、新人でも分かるように説明して」を入れ、〔　〕を選んだ状態にする |
| ［業界を説明］ | 同じ形で「〔　〕という業界を、分かりやすく説明して」 |

## H. 面談準備の質問の差し込み
- 整理の質問に「どの会社の話か」を付ける改修（AIの指示の変更）は、台本モードの後に別の作業で行う（試験環境で確かめてから反映）。
- それまでは、面談準備の質問はすべて経歴確認の最後に「全体」としてまとめて出す。
