## 4. 作り直すときの優先順位（効き目の大きい順・5つ）

1. **経歴確認を「会社ごとに一周」に直し、空白期間を会社から外す**（ズレ #11, #17。実装の `expandScenes` と `companiesFromPrep`）。今のスクリプトが「5. 経歴確認以降は使えない」と言われる最大の原因で、順番が直るだけで会話が成立する。あわせて学歴は最終学歴を拾い、高校では学部を聞かない（#10）。
2. **退職理由を「開いた質問→要約→その他は？→問題なかった点は？」の流れにし、拾う一言を短い2文（受け止め＋次の質問）に作り直す**（#18, #19）。大中小の分類はCAが面談後に入れる前提にして、面談中は本人の言葉の要約だけを残す。
3. **希望職種を「サービス説明での先取り→避けたい職種→型の切り分け→経験からの定番ルート→おすすめ1つ・次回資料」の順にし、「まだ分からない」の不具合を直す**（#3, #22）。大野が初回で最も時間をかける場面で、ここが新人に一番真似しづらい。営業の型（既存ルート／獲得／反響）、事務の二極化、ITの入り口の説明文を職種提案パターン集として用意する。
4. **仕事の中身の質問を開いた形にし、深掘り候補（比重・人数・役職の中身・数字・道具・業務の境界）をボタンで選べるようにする**（#14, #15, #16）。「1日の中で一番多かった」と毎社の「立場と数字」を外し、営業職にだけ数字を出す。
5. **要らない質問を落として初回を30分台に収める**（#5 在職確認、#13 毎社の選んだ理由、#21 入り方の前置き、#23 業種の興味理由、#28 固定残業代の全員説明、#29 事務への転勤、#30 タイピング・語学・Excel5段階、#32 大事な条件3つ）。代わりに大野が足している質問（どこまで進んだか、どんな求人に応募したか、その他の退職理由、下回る求人の扱い、生成AIの利用）を入れる。年収は「手取り・月給・賞与→額面年収」の向きの自動計算を追加する（#25, #26）。
